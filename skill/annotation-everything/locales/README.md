# 语言选择与消息契约

这份契约给后续 locale 子项复用。运行时只读这里的 `zh-CN.json` 与 `en.json`，不访问网络。

## 选择顺序

生成页面时，`--locale` 写成 `auto`、`zh-CN` 或 `en`（`en-US` 这类英文地区标签收成 `en`，`zh` / `zh-Hans` 收成 `zh-CN`）。省略时不在 `review.json` 写 `locale`。重建不带 `--locale` 时沿用已有值；旧审阅没有这个字段，仍然是中文。

页面里，浏览器按这份审阅保存的选择优先于 `review.json`。保存键是 `ae-locale:` 加上审阅标识，只存在本机浏览器，切换语言不写批注、不改审阅标识。

命令行里，`notes.py show --locale` 与 `notes.py skills --locale` 优先于环境变量 `AE_LOCALE`，再优先于审阅里的 `locale`。三级都没有时输出中文。只有选择是 `auto` 时才读 `LC_ALL`、`LC_MESSAGES`、`LANG`；匹配不到受支持的语言时用英文。

`zh-Hant`、`zh-TW` 和其他语言是非法选择。生成和 `show` 会说明原因并停下来，不改已有批注。

## 消息

语义 key 用完整句子。占位符只有 `{name}` 这一种，`{{` 与 `}}` 是字面花括号。英文计数在 key 后加 `.one` 和 `.other`，中文只用基础消息。`0`、`1`、`2` 都要能替换 `{count}`。

用户写的批注、引用和材料标题保持原文。`报告`、`讲稿`、`报告和讲稿` 仍是存储值；英文界面只改显示。`notes.py show --json` 导出这些原始值，不随语言改写。

缺译时用另一种语言的同一条 key，并留下记录。`i18n.check_catalogs()` 检查两种语言的基础 key、占位符和英文复数分支是否齐全。

页面和 Python 读同一份 JSON。页面函数是 `tMsg(key, params)`：英文按 `.one` / `.other` 选分支，中文用基础消息，整数 `count` 同时决定分支并替换 `{count}`。缺译时回退到另一种语言，并把 key 追加到 `missingKeys`（`localeMissing()` 可读）。命令行缺少占位符参数时报错并停止；页面保留 `{name}`，避免一条坏调用把界面画崩。

这条闭环里，添加按钮、对象名称、输入提示、空列表和引用来源，中英文都走词典。中文对象名保持「对象」，输入提示保持页面上原来的长句。英文 `show` 在有已初改批注时用 `cli.show.drafted` 计入条数；没有时不写这一段。

#30 之后，批注卡片上的编辑 / 保存 / 取消 / 删除 / 重新打开 / 标为已处理 / 定稿 / 退回重改 / 重新标注 / 去掉标注、隐藏与显示已处理、确认对话框、选中文字后的操作条与双侧同步、点与框的标注弹窗、风格优化的范围与输入提示、页码与统计行、讲稿栏与问答标签、编辑帮助、页头控件的提示与无障碍名称、断线与补传提示，中英文都走词典。

页面侧有两种取消息的方式，按来源选：

- **静态标记**用声明式属性——`data-msg`（可见文字）、`data-title`（`title`）、`data-aria`（`aria-label`）、`data-ph`（`placeholder`），参数用 `data-p-<名称>` 传，由 `applyMessages()` 在 `applyLocale()` 里统一刷写。带 `<kbd>` 之类兄弟节点的元素，把 `data-msg` 挂在包住文字的那个 `<span>` 上。
- **JS 动态生成的片段**在模板字符串里直接调 `tMsg()`。

切换语言是纯显示操作，但**进行中的控件状态也要重刷**：标注按钮标签、删除待确认、风格条、连接徽标都得按当前语言再画一遍，否则同一行里会留着上一种语言。

整句进词典，不要拿片段拼。英文比中文长，标点和空格要由译文自己决定（如 `viewer.pairLine`、`viewer.quoteLine`）。说明正文这类带行内标记的长文按语言整段放在模板里，用 `data-ae-lang` 切换，不进词典——词典不承载 HTML。

存储值和协议写法固定中文，不随界面语言改写：对象值 `报告` / `讲稿` / `报告和讲稿`、快捷修改的 `删除引用的这段文字` 与 `改为：`、导出里的 `风格优化：整页` 等（模板里是 `STYLE_EXPORT`，显示用 `STYLE_LABEL`）、页面键、批注 id、审阅标识。系统生成的默认说明可以跟随语言，但**能被解析还原的不行**。

#31 之后，技能输入栏与候选、推荐标记、空结果、查看全部、编辑态占位符、批注卡片上的技能标记，以及常驻技能的范围标签、弹窗、增删与保存提示，中英文都走词典；`notes.py skills --locale` 与 `show --locale` 同一套优先级。

常驻技能范围照 `STYLE_EXPORT` / `STYLE_LABEL` 的办法分成三份：`ALWAYS_SCOPES` 是存进 `skills.json` 的存储值（顺序即下拉顺序），`ALWAYS_LABEL` 是范围 → 消息 key 的显示映射（`alwaysLabel()` 是唯一入口），`ALWAYS_EXPORT` 是导出 / 导入与「交给 Agent」摘要里的协议写法、固定中文。改显示不改存储值。技能名称和说明始终用目录里的原文，不随语言改写；搜索按原文匹配，实际调用名也按原文写回。
