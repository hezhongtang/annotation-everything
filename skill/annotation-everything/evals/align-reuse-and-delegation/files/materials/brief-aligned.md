# 季度经营报告完整需求说明书（synthetic brief）

> 合成数据，仅用于评测复用既有约束与委派记录契约。

- **用途与预期行动**：用于管理层周会后决定四季度是否调整外卖定价与新店促销。
- **读者与阅读方式**：公司管理层与区域运营负责人，**独立阅读**为主（不需要讲稿）。
- **核心问题与优先级**：1) 三季度收入同比增长来源；2) 外卖与咖啡豆成本如何影响毛利；3) 数据缺口有哪些（十月与老店坪效细节放补充页）。
- **材料范围与口径**：仅纳入 materials/q3-notes.md；同比均与去年同期比较。
- **信息密度与篇幅**：信息密度按「独立阅读」；主体正文 **4 页硬上限**，使用 `data-kind="supplement"` 的补充页**不计入**正文页数。
- **视觉风格**：沿用 AE 默认中性纸面视觉，背景 `#ffffff`，主字 `#1f2933`，强调色 `#9a3412`，正文字号 `22px`，页面 `1280×720` 内边距 `64px 72px`。
- **导航设计**：**由 Agent 决定**，须支持概览把握与结论到补充页回跳。
- **使用环境与交付**：只交付 AE 对照页浏览的逐页 HTML 与核验记录。
- **讲稿与审阅重点**：**不需要讲稿**；首次进入对照页重点核对同比复算与缺口页。
