          __INTRO__
          快捷键：← → 翻页，Home / End 首末页；L 跳到上次批注的页；H 说明，N 全部批注，A 交给 Agent，J 处理记录（每次交给 Agent 算一批：解决了几条、处理摘要；先改后审的批次分初改、复核两段，可在这里请求复核或直接定稿），P 在报告上标注，C 写批注，K 填技能，G 常驻技能（每条批注按范围都让 Agent 先调用）；Esc 关闭或取消。
          布局：[ 切换侧栏，] 切换讲稿，\ 切换底部面板；F 全屏专注。全屏里 C 打开浮动输入框，⌘/Ctrl + ↵ 添加；P 标注，S 风格优化，← → 翻页，选中文字后 D / R / C 照常可用；Esc 先关闭浮层，再退出全屏。输入框聚焦时不触发布局快捷键。
          
在报告上标注（P）：进入标注后，在报告上单击放一个点，或按住拖动框选一块区域（像截图那样），再写意见。点和框都可以直接拖动，框拖右下角可调大小；点一下弹出这条批注的编辑、标为已处理、去掉标注、删除；鼠标移到批注列表上，对应标注会高亮。已有的批注在「编辑」里可以补标注或重新标注。
          
风格优化（S）：选范围——1 整页、2 标注处（用刚放的点或框；还没有就进入标注）；可写想要的方向（不写也行），再添加批注。
          
「技能」：某条批注需要特定技能（skill）才能改好时填上，多个用逗号分隔；Agent 处理这条前会先调用它们。候选来自技能目录和用过的技能，会参考当前审阅和批注给出建议；可查看全部，或按名称、说明搜索，用上下方向键和回车选择；搜不到时会说明没有匹配的技能。技能名称和说明始终用目录里的原文，不随界面语言改写。
          
选中报告或讲稿里的文字后：D 删除这段（再按一次 D 或 ↵ 确认，防止打字时误触），R 改为…（在弹出的框里改好按 ↵），C 以它为引用写批注；另一侧同一页有相同或相近的句子时会提示「同时改」（默认勾选，B 切换）。写批注时 ⌘/Ctrl + ↵ 添加。
          
批注保存：用本地服务打开（地址是 http://127.0.0.1:端口）时，每次改动自动写入审阅目录的 notes.json，Agent 可直接读取；直接双击打开 HTML 时批注只存在本浏览器，用「复制全部」或「下载」交给 Agent。
          

          Shortcuts: ← → change page, Home / End for the first and last page; L jumps to the page of the last annotation; H help, N all annotations, A hand to the agent, J processing history (each hand-off counts as one batch: how many it solved and its summary; a draft-then-review batch splits into a draft stage and a review stage, and you can ask for the review or finalize it here), P annotate on the report, C write an annotation, K fill in skills, G standing skills (every annotation asks the agent to call them first, by scope); Esc closes or cancels.
          Layout: [ toggles the sidebar, ] toggles speaker notes, and \ toggles the bottom panel; F enters focus mode. In focus mode, C opens the floating composer and ⌘/Ctrl + ↵ adds an annotation; P marks the report, S opens Style, ← → changes page, and D / R / C work on selected text. Esc closes the current overlay before leaving focus mode. Layout shortcuts do not run while typing.
          
Annotate on the report (P): once you are in marking mode, click on the report to drop a pin, or hold and drag to select an area (like a screenshot), then write your request. Pins and areas can both be dragged, and an area is resized from its bottom-right corner; click one to edit that annotation, mark it resolved, remove the mark or delete it; hover an annotation in the panel and its mark lights up. An existing annotation can be given a mark, or re-annotated, from Edit.
          
Style (S): choose a scope — 1 whole page, 2 at the mark (the pin or area you just placed; if there is none, marking mode starts); you can write the direction you want (or leave it empty), then add the annotation.
          
"Skills": when an annotation needs a particular skill to be done well, fill it in and separate several with commas; the agent calls them before handling this annotation. Candidates come from the skill catalog and the skills already used, with suggestions based on the current review and its annotations; you can see them all, or search by name or description, and choose with the arrow keys and Enter; when nothing matches it says so. Skill names and descriptions always stay as the catalog has them and are not rewritten for the interface language.
          
After you select text in the report or the speaker notes: D deletes it (press D or ↵ again to confirm, so typing does not trigger it by accident), R replaces it (edit it in the box that opens and press ↵), C writes an annotation quoting it; when the other side has the same or a similar sentence on this page you are offered "change both" (ticked by default, B toggles). While writing an annotation, ⌘/Ctrl + ↵ adds it.
          
Where annotations are kept: when you open it through the local service (the address is http://127.0.0.1:port) every change is written straight into the review directory's notes.json, which the agent can read; when you open the HTML by double-clicking, annotations live only in this browser — use "Copy all" or "Download" to hand them to the agent.
